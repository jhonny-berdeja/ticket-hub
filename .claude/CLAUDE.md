# ticket-hub

Este proyecto es el frontend de una ticketera, mediante el cual se solicita la gestión del servidor pcbox, la gestión de bases de datos y la gestión de Kubernetes del ecosistema jtagram.

Las convenciones de desarrollo de los workflows de GitHub Actions **no** viven acá: están en el proyecto padre `jtagram`, en `.claude/infra/`.

Las convenciones de desarrollo de frontend tampoco viven acá: están en `jtagram/.claude/front/`.

## Regla

Antes de desarrollar algo en este repo, asegurate de tener clonado el padre `jtagram` (como carpeta padre) para tener disponibles esas guías de convenciones.
